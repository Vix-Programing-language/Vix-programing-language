## Why Vix?
Vix is a perfect language for anyone who is new to programming or a developer who want to start into low level developement with simple syntax and usage. Also vix prevides a safety features by default e.g Optional ARC ( in stdlib )/Auto clone/Thread safety features.

Also, outside this language low level focusing, it's also so good for high level tasks!

- **Performance:** Vix is a perfect example for a high performing language. It's fast for being compiled and optimized! At both compiling time and run time also!
- **Reliability:** Vix has alot of features you may need for both low level work and high level too. Without any overhead from a GC etc.. Also previde full control over the memory and the compiler it self
- **Learning:** Vix is simple language. So easy to learn both syntax and how to use it.  [Get Started](https://vixlanguage.github.io/getstarted) to the language and you might have fun trying it and can reach even high projects with the fast run time performance

## Get started
> **Warning:** There is no offical installion for the current alpha version. Please seek out for a future updates!

First install vix from our [Website](https://vixlanguage.github.io/installion) or directly from [github releases](https://github.com/Vix-Programing-language/Vix-programing-language/releases) select the latest version and find your OS and installion should begin! After installion go ahead and make a new file call it whatever you want and don't forget to add '.vix' as the extension example `main.vix`.

Next step is to open a terminal and type out the command.
```bash
vix run yourfile.vix` # example main.vix
```

Another option is to use `vix new name` command. Make automatically a folder asigned with the name u choose containing 'src/' folder and 'config.toml' file used for compiler configing stuff ( optional ).

After that open your file like 'src/main.vix' if you used 'vix new' command. And type in. example:

```vix
print("Hello, world!")
```

Then run your first program in vix!
